# vganalyzer

the basic functionality is done, easy to work with:

## 0. connect the phone and the pc to the same network
## 1. run the django server online
## 2. run `ipconfig` command in the terminal in the pc
## 3. open the app and enter the value of the IPv4 Address in the phone,, example: 192.168.99.240
## 4. press the accept button in the app in the phone
done!

note: the fast button was built for personal use, it won't work for you...
