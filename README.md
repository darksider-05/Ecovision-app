## how to use:
### 0. connect the phone and the pc to the same network
### 1. run the django server online (run something like ```python manage.py runserver 0.0.0.0```)
### 2. run `ipconfig` command in the terminal in the pc
### 3. open the app and enter the value of the IPv4 Address in the phone,, example: 192.168.99.240
### 4. press the accept button in the app on the phone
done!

note: the fast button was built for dev use, it won't work for you...
